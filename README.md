# penguin-hockey

펭귄 하키 — 한 파일로 실행되는 Three.js 아케이드 하키 게임 (플레이스토어 게시용).

- 완성 파일: `penguin-hockey-improved.html` (three.js 포함, 2MB 이하)
- 빌드: `python3 apply_v10.py`
- 테스트: `bash runsuites.sh` (단위), `br/` (실제 브라우저, `cd br && npm ci`)
- 작업 방법과 규칙: [CLAUDE.md](CLAUDE.md)

현금 결제 없음 · 저장 데이터(`penguinHockey.v1`)는 항상 하위 호환.
