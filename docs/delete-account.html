  2. 계정 · 클라우드 저장 줄의 관리 버튼을 누릅니다.

  3. 요청을 확인한 뒤 7일 이내에 계정과 클라우드 세이브를 삭제하고, 결과를 메일로 알려 드립니다.

본인 확인을 위해 요청 메일의 발신 주소가 Google 계정 이메일과 같은지 확인할 수 있습니다.

  • Google 계정 정보와 익명 사용자 ID

  • 친구 대전 방 정보와 출석 기록(클라우드에 남아 있는 경우)
